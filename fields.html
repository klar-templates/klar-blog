Heading Block

Understanding Rich-Text Blocks

A blocks field stores an array of HTML snippets — each block is independently editable and can be reordered via drag-and-drop in the editor panel. This is Klar's rich-text field, designed for article bodies and long-form content.

Blocks can mix headings, paragraphs, lists, and blockquotes freely. Each block renders as its own HTML element, giving you full control over structure and formatting.

New paragraph

  • Headings (H2, H3, H4) for structure
  • Paragraphs with inline formatting
  • Bullet and numbered lists
  • Blockquotes for emphasis
Blocks are the preferred way to author rich article content in Klar — they map directly to editable regions in the visual editor.
