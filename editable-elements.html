Klar Reference

Editable Elements

Editable Elements tell Klar which parts of your page can be edited — and how.
It works like CSS: you target elements with selectors, then attach behaviors with :directives. Where CSS says "make .hero blue," Klar says "make .hero editable."

"It's CSS, but for editability"

.selector :list :blocks :attr :style :exclude :readonly :snapshot :htmlBlocks

Grouped by what you want to do

Every rule is a selector plus, optionally, one or more directives. There are only four kinds — pick the ones that match your intent.

Make it editable

Point at an element to make its text click-to-edit. This is all most pages need.

.hero
Choose a field type

Edit it as a specific kind of value — a date, tag list, image, or a raw attribute.

:field:attr:style
Add & reorder

Let editors add, remove and reorder items or drag-and-drop blocks.

:list:blocks:htmlBlocks
View-only & frozen

Set parts off-limits, view-only, or frozen at save time.

:exclude:readonly:snapshot

Live demos

Each card shows real website content with a directive applied. The text explains exactly what an editor can and can't do.

1

.selector

.hero

Welcome to Nexus

Your editing journey starts here. Click any text to change it — headings, paragraphs and links all become editable.

Get started →

A selector with no suffix simply marks an element as editable. The element itself and its default-editable descendants — headings (h1–h6), paragraphs, links, buttons and list items — become click-to-edit. Click the heading or paragraph above and start typing.

Once your editableSelectors list is non-empty, editability is opt-in — only listed selectors and their default-editable children can be edited.
2

List

.features:list
⚡ Lightning fast
🔒 Secure by default
✨ Easy to use

Marks a repeatable container. Its direct children become items the editor can duplicate, reorder and remove — perfect for feature grids, card rows, stats and steps.

  • Each pill above is one repeatable item — add a fourth by copying an existing one.
  • Drag to reorder, click to remove.
  • Alias: .features[] means the same thing.
3

Blocks

.content:blocks

Drag and drop story

Each block — this heading, this paragraph, and the image below — can be dragged to reorder, added or removed.

Turns the element into a drag-and-drop block container. A user can add, reorder and remove content blocks — headings, paragraphs, images and more — dragging pieces into the order that tells the story, rather than editing a fixed layout.

4

Attribute

img.avatar:attr(alt)
Sarah Chen The image stays put — its alt text is editable in the panel, not the picture itself.

Makes an element's attribute editable rather than its text. The editor exposes the named attribute in the panel — like the alt text above — so a user can change it without touching inline content. Perfect for accessibility text on logos and avatars.

.selector:attr(class) Edit the element's classes — the panel shows a class editor (add or remove class pills, or pick from your design system) instead of raw text.
.selector:attr(style) Edit inline styles through a visual property editor — spacing, color, borders and more, grouped like a design tool.
5

Style

.hero__bg:style(background-image)

Adventure Awaits

Swap this background through the media picker — no code needed.

Lets a user edit the element's CSS background-image through Klar's media picker. Instead of editing text, they swap the background by choosing a new photo — ideal for hero bands and cover panels where the picture is applied as a background rather than an <img>.

6

Exclude

.hero:exclude(img, a)

Limited Edition Sneaker

The image and link are locked — edit the title and description freely without worrying about the picture.

View product →

Keeps the container editable but carves specific descendants out of it. Everything inside stays click-to-edit except the elements matched in the parentheses.

  • The title and description above stay editable.
  • The img and a are frozen — no accidentally retyping the link or deleting the image.
  • Use it to protect structural or decorative pieces inside an otherwise-editable block.
7

Read-only

footer:readonly

© 2026 Nexus Blog. All rights reserved. This footer is visible in the editor but locked — no accidental edits.

The element is selectable and listed in the editor panel, but not inline-editable. A user can see it and click it, yet can't change its content directly — useful for legal footers, shared boilerplate, or anything that shouldn't be casually rewritten.

8

Snapshot

.cached-price:snapshot
Price at publish $249.00 Frozen Jan 15, 2026

The price was captured at save time. Even if the live price changes, this value stays locked at what it was when published.

Freezes the element's content at save time — whatever it contains the moment you save is captured as plain HTML and locked in. Freezing makes it read-only too, so the frozen content can't be edited inline either. It's built for JavaScript-rendered content: a script fills the element on load, and :snapshot bakes whatever it produced into the saved static HTML — so a computed value or timestamp is committed to the page once, instead of being regenerated on every visit.

9

htmlBlocks

.layout:htmlBlocks
Zone A

Each nested container becomes its own block zone. Add blocks here independently.

Zone B

A separate block zone — drag blocks here without affecting the sidebar.

Like :blocks, but it also auto-discovers nested container descendants as block zones. One directive on an outer wrapper turns every nested container inside it — like Zone A and Zone B above — into its own drag-and-drop region. Ideal for multi-zone layouts where several areas should each accept blocks.

Reference

Every directive at a glance. Stack as many as you need on one selector.

Directive What it does Example
Target
.selector Makes the matched element's text click-to-edit — the starting point for every rule. .hero, .lead
Field types
:field(…) Turn it into a typed field — text, date, number, tags, image and more. See Field Types. .date:field(type:date)
:attr(name) Make an attribute editable (alt, href, data-*). Use :attr(class) or :attr(style) for the class and style editors. img.logo:attr(alt)
:style(prop) Edit a CSS property through a picker — e.g. swap a section's background image. .hero:style(background-image)
:wrap(…) · :editor · :format Control inline formatting — wrap a selection in a tag/class, with optional styled choices. Three names, same behavior. .body:wrap(span.class[Red=text-red-500])
Repeat & arrange
:list Add, reorder and remove list items. .posts:list
:blocks Drag-and-drop block container — headings, text, images and more. .content:blocks
:htmlBlocks Like :blocks, and auto-discovers nested containers as their own block zones. .layout:htmlBlocks
Limit
:exclude(sel) Carve matching descendants out of editing. .card:exclude(.price)
:readonly Selectable and listed in the panel, but not inline-editable. footer:readonly
:snapshot Freeze the content at save time (read-only too). .cached-price:snapshot
Advanced
:config(…) Per-selector settings — e.g. which class marks the active item in a nav. .nav-link:config(active: is-active)

Directives shape the editing experience.

Combine a .selector with :exclude, :attr, :list and the rest to decide exactly what your editors can touch — and what stays safe.
